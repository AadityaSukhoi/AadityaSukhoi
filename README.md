## About Me

I'm a Computer Science student with a strong interest in AI software engineering and backend development.

I enjoy building complete applications from the ground up, understanding how every component works, and turning ideas into working products. Whether it's designing APIs, integrating LLMs, working with vector databases, or deploying backend services, I like knowing what's happening under the hood instead of treating systems as black boxes.

During my internship at **Opkey**, I worked on production AI applications using Python, FastAPI, LangChain, Ollama, Qdrant, Redis, Docker, GitHub Actions, CI/CD, Linux, and Langfuse. More than the technologies, the experience taught me how to write software that's maintainable, reliable, and built for real-world use.
